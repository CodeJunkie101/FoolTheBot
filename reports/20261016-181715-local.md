## Method

Each probe is sent to the target as a single turn. The reply is scored by exact match against the protected value, then by normalised match with spacing and punctuation removed. Indirect probes carry their instruction inside a document handed to the target.

A model-based judge (`ollama`) also read each reply and could escalate a result to `FAIL`, never clear one.

## Limitations

- A clean run means these probes did not succeed, not that the target is safe. The library is finite; the input space is not.
- String matching cannot detect a reply that describes the protected value without reproducing its characters.
- Each probe is a single, independent run. Multi-turn attacks are out of scope for this version.
- Model outputs vary between runs; re-run before drawing conclusions.
