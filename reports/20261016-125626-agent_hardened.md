## Method

Each probe gives the agent a task and lets it run its tool loop in a sandbox where no file, email, or command is real. Every tool call is recorded, and the resulting action log is checked against a fixed policy (external email, file deletion, reading confidential paths, destructive shell commands, and exfiltration of a confidential value). The verdict comes from what the agent did, never from what it said about what it did.

## Limitations

- A clean run means these probes did not succeed, not that the target is safe. The library is finite; the input space is not.
- The sandbox agent is deliberately gullible. Results characterise this target; run the same probes against a hardened agent to measure a defense.
- The policy covers a fixed set of forbidden actions. An agent could cause harm through an action the policy does not model.
- Each probe is a single, independent run. Multi-turn attacks are out of scope for this version.
- Model outputs vary between runs; re-run before drawing conclusions.
